# MarieMe

Mon tableau de bord personnel : application web installable (iPhone et PC).

- `index.html` : toute l'application (structure HTML, style CSS, logique JavaScript)
- `manifest.webmanifest` : nom, couleurs et icônes pour l'installer comme une appli
- `sw.js` : permet à l'appli de s'ouvrir sans connexion
- `icons/` : icônes de l'appli

Les données personnelles ne sont **pas** dans ce dépôt : elles restent sur chaque appareil, dans le stockage du navigateur, chiffrées si un code est activé.
